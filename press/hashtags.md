# Hashtag sets per platform

Curated, tested combinations. Mix from these — don't use *all* of them per post.

> 🎯 Rule of thumb: **3-5 hashtags max** on Twitter/Bsky/Threads. **5-10** on Instagram/TikTok/LinkedIn. More than that signals spam.

---

## Twitter / X / Bluesky

Core launch:
```
#gamedev #indiegame #cardgame #webdev #foss
```

Tech angle:
```
#javascript #vanillajs #webrtc #pwa #peerjs
```

Game theory / nerd:
```
#gametheory #boardgames #strategygame
```

Daily challenge / Wordle angle:
```
#dailygame #wordle #wordlealike
```

## Reddit (no hashtags — but title flair matters)

Reddit doesn't do hashtags. Instead:
- **r/WebGames**: tag `[I Made This]` if available
- **r/boardgames**: tag `[Online]` or `[Free]`
- **r/cardgames**: any tag is OK
- **r/programming**: no tags; title must include "Show HN"-style phrasing
- **r/indiegames**: `[Game]` tag
