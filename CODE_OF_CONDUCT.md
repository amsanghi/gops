# Code of conduct

We want GOPS to be a friendly project where anyone can contribute, play, or hang around.

## In short

- **Be kind.** Disagreement is fine; rudeness isn't.
- **Be patient.** This is a hobby project. Reviews may take a while.
- **Be inclusive.** Assume good faith. Welcome newcomers and explain things.

## Not OK

- Personal attacks, slurs, harassment, doxxing
- Spam, off-topic political/marketing posts in issues
- Posting other people's private info
- Cheating (in-game, e.g. modifying localStorage to game leaderboards is fine; griefing other players in multiplayer is not)

## Enforcement

Issues and PRs that violate this code will be edited or closed. Repeated bad faith may result in a ban from the repo.

If something feels off, open a private GitHub Security Advisory or email the maintainer directly. We'll handle reports discreetly.
